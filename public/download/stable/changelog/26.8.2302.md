# 26.8.2302

## 修复
- 改进 zstd.dll 加载失败诊断，并确保发布包使用构建目录中的 DLL。
- 修复导出事务在文件重命名导致 Windows 文件 ID 改变时的恢复误判。
- 放宽预览导出速度上限至 1024 倍，并补充相关可靠性测试。
- 修复预览器封装完成后未传递输出 MP4 路径的问题，恢复完成提示中的文件引用和打开 MP4 操作。

## 性能
- 优化统一输出尺寸封装：同尺寸帧直接复用像素缓冲，缩放路径复用输出缓冲并缓存帧索引，降低逐帧转换和重复读取的开销。

## 本月历史更新

合并版本：26.8.2301、26.8.2000、26.8.1400、26.8.832。

### 26.8.2000

#### 修复
- 修复一项dll引用错误

### 26.8.1400

合并范围：26.7.1530 至 26.8.1312。

#### 录制与交互
- 完善 SAI 2026.07.08 的历史记录支持。
- 新增录制管理功能，补充 WebUI 录制诊断日志。
- 改善封装性能、运行性能和交互细节。

#### 修复
- 修复因分段文件过多导致封装报错的问题。
- 修正脏区标记和视口标记的显示位置。
- 修复切换画布时画面不刷新的问题。
- 尝试修复封装黑屏。

### 26.8.832

#### 重点更新
- 完善多版本 SAI2 识别与主动扫描，改善高频绘制、画布切换和撤销时的预览及录制稳定性。
- 新增录制项目管理、回收站、缩略图，以及保存路径、单文件夹和分段大小设置。
- 完善视口、缩放、旋转、指针、脏区及录制筛选信息的读取与预览。
- 视频封装支持内置编码器与 FFmpeg，自动模式优先使用可用的 GPU 编码能力。
- 更新主题、字体、自定义画笔和窗口设置，并改善录制、预览及封装错误提示。

#### 使用提示
- RecSAI 与 SAI2 权限不一致时可能无法附加，请使用相同权限启动。
- SAI2 2026.07.08 及后续版本可能缺少部分历史类型，相关显示与录制筛选会自动降级。
- 超过 10000 × 10000 的画布不建议录制 L0；请改用 L1 或更低细节级别。
